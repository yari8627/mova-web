# Google sign-in assets

Used only by the authentication Google button; downloaded 2026-10-27 from Google.

- `google-g.png`: unchanged official icon, https://developers.google.com/static/identity/images/g-logo.png
- `google-sans-medium.ttf`: official Google Fonts subset for “Continua con Google”, weight 500 (4,244 bytes). Source stylesheet: https://fonts.googleapis.com/css2?family=Google+Sans:wght@500&display=swap&text=Continua%20con%20Google
- Font license: `google-sans-OFL.txt`, https://raw.githubusercontent.com/google/fonts/main/ofl/googlesans/OFL.txt

Branding reference: https://developers.google.com/identity/branding-guidelines
No Google OAuth configuration or SDK has been changed. NAMI uses the existing `NamiWordmark` component, not these assets.
